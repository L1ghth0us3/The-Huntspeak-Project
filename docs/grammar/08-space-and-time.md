# 8. Space and Time

## Positionals

These sit before the noun phrase, like English prepositions. Some track **motion**, others **position**.

### Motion

| Huntspeak | Meaning | Typical use |
| --- | --- | --- |
| däya | down | walking **down** something |
| asu | up | pushing **up**, looking **up** |
| saae | out of | taking something **out of** |
| i'saae | into | putting something **into** |
| ayu | toward, to | moving **towards** |
| sula | away | moving **away** from |
| äsaq | past | moving **past** |
| uisa | over | moving **over** |
| qaal | onto | moving **onto** |
| eryet | off | taking **off** |
| lium | around | walking **around** |
| nui | along | walking **along** |
| anash | across | moving **across** |
| yurad | through | walking **through** |

### Position

| Huntspeak | Meaning |
| --- | --- |
| yat | in |
| laya | on |
| vayu | next to |
| abiya | between |
| inela | among |
| dakhan | in front of |
| heidu | behind |
| ehyu | above |
| dahu | below |
| eenab | under |
| shila | near |
| ayar | far |
| uan | from |
| isea | left (“to my left”) |
| yama | right (“to my right”) |

> **Î vîset däl tye yat wäwi.** - “I saw many animals in the forest.”
> **…se vesut asu ada mithra shiä…** - “…she looked up at the holy moon…”

`yat` “in” also works for abstract targets: `muvat yat shiä` “trust in the moon”.

## Temporals

| Huntspeak | Meaning |
| --- | --- |
| itâ | now |
| eene | later |
| ashad | during |
| avikh | after |
| eshu | while |
| tarem | before |
| udil | then, next |
| îtâsh | still (“I am still eating”) |
| nanaqa | at the same time |
| shrala'i | long ago |

`eshu`, `avikh`, `tarem`, and `udil` can also link whole clauses - see chapter 10.

## Days and nights

Compounds with `ädi` “day” and `shiä` “moon” cover the basics (chapter 9 explains compounding):

| Huntspeak | Literally | Meaning |
| --- | --- | --- |
| layädi | on-day | today |
| vayädi | next-to-day | tomorrow |
| heyädi | behind-day | yesterday |
| kharashiä | this-moon | tonight |
| mîdam | - | morning (sunrise to noon) |
| nätum | - | night (dusk to dawn) |
