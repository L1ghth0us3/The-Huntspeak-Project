# Voice for learner docs

When you edit introduction, pronunciation, grammar, phrasebook, tables, or examples:

- Talk to the reader as **you**.
- Open with what they’ll be able to **say or do**.
- Prefer “we write X” / “you’ll see Y” over “attested,” “authority,” “learner-facing.”
- Mark **provisional** material with a short aside (“still settling — fine for RP”), not a bureaucratic banner.
- Keep process links (`GOVERNANCE`, decision IDs) out of the main teaching flow; put trails in footnotes or `development/` when a spelling change needs history.
- Show dialogue and concrete examples early on usage pages.
